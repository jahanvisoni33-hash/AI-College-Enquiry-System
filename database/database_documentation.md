# Database Documentation

## Project
AI Chatbot College Enquiry System

## Database Name
college_enquiry

## University
ACNJ University

## Tables

| Table | Purpose |
|---|---|
| university_info | Stores general information about ACNJ University |
| departments | Stores department details |
| courses | Stores courses offered by the university |
| admissions | Stores admission process and requirements |
| fees | Stores course fee details |
| facilities | Stores available university facilities |
| faqs | Stores frequently asked questions and answers |
| admins | Stores administrator information |
| chat_history | Stores chatbot conversation history |
| feedback | Stores user feedback and ratings |

## Relationships

- One department can have many courses.
- One course can have many admission records.
- One course can have many fee records.
- One chat session can have multiple feedback records.

## Main Database Functions

The database provides information about:

- University details
- Departments
- Courses
- Course eligibility
- Course duration
- Admission process
- Required documents
- Selection process
- Application dates
- Fees
- Facilities
- Frequently asked questions
- Chat history
- User feedback
